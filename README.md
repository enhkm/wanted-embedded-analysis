# 원티드 임베디드 채용 공고 분석

원티드 **개발 › 임베디드 개발자 외 1개 직무** 필터의 공고 241건(2026-10-12 수집)에서 자격요건과 우대사항을 정리하고, 이를 바탕으로 취업 학습 로드맵을 만들었습니다.

| 폴더 | 내용 |
| --- | --- |
| [`dashboard/`](dashboard/) | 채용 요건 대시보드. 요건별 빈도, 경력·지역 분포, 공고별 원문 검색 |
| [`roadmap/`](roadmap/README.md) | 임베디드 개발자 취업 학습 로드맵 보고서 |
| [`data/`](data/) | 공고 데이터(`postings.json`)와 요건 키워드 집계(`keywords.json`) |

## 대시보드 보기

`dashboard/index.html`을 브라우저로 열면 됩니다. 데이터는 `dashboard/data.js`에 들어 있어 서버 없이 동작하고, 차트 라이브러리(d3)만 인터넷에서 불러옵니다.

## 데이터

- `postings.json`: 공고 1건당 회사, 포지션, 근무지, 최소·최대 경력, 필수·우대 요건 키워드, 자격요건·우대사항 원문, 원티드 링크
- `keywords.json`: 68개 요건 키워드별로 자격요건(필수)에 적은 공고 수와 우대사항에만 적은 공고 수

요건 키워드는 공고 본문을 키워드 매칭으로 집계한 것이라 특이한 표현은 빠졌을 수 있습니다. 공고 원문의 저작권은 각 채용 기업과 원티드에 있습니다.
